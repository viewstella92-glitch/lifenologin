# Life Dashboard 🌸

ติดตามกิจวัตร รายรับรายจ่าย และอารมณ์ไว้ในที่เดียว พร้อมผู้ช่วย AI (ไม่บังคับ)
สร้างด้วย Next.js + Supabase และใช้ Gemini API (แพลนฟรี) สำหรับฟีเจอร์ AI

โฟลเดอร์นี้เป็นโปรเจกต์ที่ครบสมบูรณ์ แตก zip แล้วนำไปขึ้น GitHub และ Vercel ได้เลย

## มีอะไรบ้าง

**หน้าวันนี้ (`/`)**
- ติ๊กกิจวัตรประจำวัน พร้อม streak (จำนวนวันต่อเนื่อง) และแถบความคืบหน้า
- สรุปรายรับ รายจ่าย คงเหลือของเดือนนี้ และฟอร์มบันทึกรายการ
- ช่อง "พิมพ์แล้วให้ AI จดให้" เช่น `กาแฟ 65 บาท เมื่อเช้า` (ต้องมีคีย์ AI)

**หน้าภาพรวม (`/insights`)**
- บันทึกอารมณ์รายวัน, ปฏิทินสีความสม่ำเสมอ 17 สัปดาห์, อัตราสำเร็จ 30 วัน
- กราฟรายจ่ายรายสัปดาห์, สัดส่วนรายจ่ายตามหมวด, งบประมาณรายเดือนต่อหมวด
- ถาม AI สรุปสัปดาห์หรือถามเรื่องข้อมูลของตัวเอง (ต้องมีคีย์ AI)

ถ้าไม่ใส่คีย์ AI ฟีเจอร์ AI จะถูกซ่อนไว้เอง ส่วนอื่นใช้งานได้ปกติ

## โครงสร้างโฟลเดอร์

```
life-dashboard/
├── app/
│   ├── page.tsx            หน้าวันนี้
│   ├── insights/page.tsx   หน้าภาพรวม
│   ├── api/ai/route.ts     ระบบ AI (ทำงานฝั่งเซิร์ฟเวอร์)
│   ├── layout.tsx
│   └── globals.css
├── components/QuickAdd.tsx ช่องพิมพ์แล้วให้ AI จด
├── lib/                    ตัวเชื่อม Supabase, สไตล์กลาง, ตัวเช็กว่ามีคีย์ AI ไหม
├── supabase/
│   ├── schema.sql          ตารางหลัก (รันก่อน)
│   ├── phase2.sql          อารมณ์ งบประมาณ ตัวนับการใช้ AI (รันทีหลัง)
│   └── phase3_no_login.sql ปิดระบบ login (โหมดใช้คนเดียว รันเป็นอันสุดท้าย)
├── package.json            ต้องอยู่ที่ระดับบนสุดของ repo
└── .env.local.example      ตัวอย่างค่าที่ต้องตั้ง
```

## ขั้นตอนติดตั้ง

### 1. ตั้งฐานข้อมูล Supabase (ทำครั้งเดียว)

1. เปิดโปรเจกต์ Supabase ที่จะใช้ แล้วเข้าเมนู **SQL Editor**
2. คัดลอกเนื้อหา `supabase/schema.sql` ทั้งหมดไปวาง แล้วกด **Run**
3. เปิด query ใหม่ (New query) คัดลอก `supabase/phase2.sql` ไปวาง แล้วกด **Run**
4. เปิด query ใหม่อีกครั้ง คัดลอก `supabase/phase3_no_login.sql` ไปวาง แล้วกด **Run** (ปิดระบบ login ให้ทุกเครื่องใช้ข้อมูลชุดเดียวกัน และใส่หมวดหมู่เริ่มต้นให้)

อย่ากด Run ไฟล์เดิมซ้ำ เพราะจะขึ้น error ว่า "already exists"

### 2. นำโค้ดขึ้น GitHub

1. แตก zip แล้วเข้าไปในโฟลเดอร์ `life-dashboard`
2. ที่หน้า repo บน GitHub กด **Add file → Upload files**
3. ลากไฟล์และโฟลเดอร์ **ที่อยู่ข้างใน** ทั้งหมดไปวาง (ไม่ใช่ลากตัวโฟลเดอร์ `life-dashboard` ทั้งอัน) จนที่หน้าแรกของ repo เห็น `package.json` อยู่ด้านบนสุด
4. กด **Commit changes**

### 3. Deploy บน Vercel

1. เข้า vercel.com → **Add New → Project** แล้วเลือก repo ของคุณ
2. ข้ามส่วน Integrations ที่ Vercel แนะนำ (โดยเฉพาะอย่าเพิ่ม Supabase integration เพราะอาจไปสร้างโปรเจกต์ Supabase ใหม่)
3. เปิดส่วน **Environment Variables** แล้วเพิ่มค่าตามตารางด้านล่าง
4. กดปุ่ม **Deploy** (เลื่อนหน้าลงมาจะเจอ) แล้วรอ 1-2 นาที

หน้า Import เป็นแค่ขั้นตั้งค่า เว็บจะยังไม่ขึ้นจนกว่าจะกด Deploy

### 4. เปิดใช้งาน

เปิดลิงก์เว็บจาก Vercel ได้เลย ไม่ต้องสมัครหรือเข้าสู่ระบบ ทุกเครื่องที่เปิดลิงก์เดียวกันจะเห็นข้อมูลชุดเดียวกัน

### ทางเลือก: รันในเครื่องตัวเอง

```bash
npm install
cp .env.local.example .env.local   # แล้วแก้ค่าในไฟล์ให้ครบ
npm run dev                        # เปิด http://localhost:3000
```

ต้องมี Node.js เวอร์ชัน 20 ขึ้นไป

## ค่า Environment Variables

| ชื่อ (พิมพ์ให้ตรงเป๊ะ) | ค่า | จำเป็น |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL จาก Supabase → Project Settings → API | ต้องมี |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | คีย์ **anon / publishable** จากหน้าเดียวกัน | ต้องมี |
| `GEMINI_API_KEY` | คีย์ฟรีจาก aistudio.google.com → Get API key | ไม่บังคับ (ไม่ใส่ = ซ่อน AI) |
| `GEMINI_MODEL` | ชื่อรุ่น Gemini ถ้าอยากเปลี่ยน (ค่าเริ่มต้น `gemini-2.5-flash-lite`) | ไม่บังคับ |

หลังเพิ่มหรือแก้ค่าบน Vercel ต้องไปที่ **Deployments → จุดสามจุดของอันบนสุด → Redeploy** ค่าใหม่จึงจะมีผล

## แก้ปัญหาที่เจอบ่อย

- **เข้าหน้า Import หลายรอบแต่เว็บไม่ขึ้น**: ยังไม่ได้กด Deploy ให้เลื่อนหน้าลงแล้วกดปุ่ม Deploy
- **Build Failed หรือหา `package.json` ไม่เจอ**: ไฟล์ขึ้น GitHub ผิดชั้น ต้องให้ `package.json` อยู่ที่ระดับบนสุดของ repo (ดูขั้นตอนที่ 2)
- **ไม่เห็นปุ่ม AI**: ยังไม่ได้ใส่ `GEMINI_API_KEY` หรือยังไม่ได้ Redeploy หลังใส่
- **AI ขึ้นข้อความผิดพลาด**: อาจใช้ครบโควตา 30 ครั้งต่อวันของแอป หรือโควตาฟรีของ Google เต็ม ลองใหม่ภายหลัง หรือเปลี่ยนรุ่นด้วย `GEMINI_MODEL`
- **เว็บโหลดไม่ขึ้นหลังไม่ได้ใช้นาน**: Supabase จะ pause โปรเจกต์ฟรีที่ไม่มีการใช้งานราว 1 สัปดาห์ ให้เข้า dashboard ของ Supabase แล้วกด Restore/Resume

## ความปลอดภัยและข้อควรรู้

- **โหมดไม่มี login**: ใครก็ตามที่เปิดเว็บได้ (หรือเรียก API ของ Supabase ตรงๆ ด้วยคีย์ที่อยู่ในโค้ดหน้าเว็บ) จะอ่านและแก้ข้อมูลทั้งหมดได้ เหมาะกับใช้คนเดียวและเก็บข้อมูลที่ไม่ละเอียดอ่อน ไม่ควรพิมพ์ข้อมูลส่วนตัวมากๆ ลงในโน้ต
- ใช้เฉพาะคีย์ **anon / publishable** ในโปรเจกต์นี้ ห้ามนำ `service_role` หรือ secret key มาใช้ และห้ามใส่คีย์ AI ในชื่อที่ขึ้นต้นด้วย `NEXT_PUBLIC_`
- ไฟล์ `.env*` ถูกตั้งให้ Git ข้ามไปแล้ว (`.gitignore`) คีย์จะไม่หลุดขึ้น GitHub โดยไม่ตั้งใจ
- ระบบ AI จำกัดรวม 30 ครั้งต่อวัน (ปรับได้ที่ `DAILY_LIMIT` ใน `app/api/ai/route.ts`)
- แพลนฟรีของ Supabase ไม่มี backup อัตโนมัติ ควรสำรองข้อมูลไว้เป็นระยะ
- แพลนฟรีของ Gemini อนุญาตให้ Google นำข้อความที่ส่งเข้าไปมาใช้พัฒนาโมเดลได้ จึงไม่ควรพิมพ์ข้อมูลละเอียดอ่อนในช่องโน้ต
